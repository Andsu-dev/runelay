Set up runelay

A few minutes from zero to every agent connected. Follow the steps, or hand the whole thing to your agent.

Let Claude Code do itCopy the instructions, paste them into Claude Code (or Codex, Cursor, any agent with a terminal) and it installs for you.

Step by step

No terminal? Download the desktop app for Mac, Windows or Linux. After you create your account, Connect my agents and Connect my accounts do the rest. The steps below are for a server and the terminal.

  1. 1

    Install the server

    On any machine with Docker: a VPS, a home server or this laptop.

    $curl -fsSL runelay.com/install | sh

    It writes ~/runelay/.env with a fresh RUNELAY_SECRET. Back it up: without it, your connections cannot be opened.

    Rather not use Docker? Download the desktop app instead.

  2. 2

    Create the owner account

    Open the first-access link the installer prints. It works once; after that, signups close.

  3. 3

    Connect this computer

    One line installs the CLI and runs runelay setup with your server's address (or the one the desktop app shows).

    $curl -fsSL runelay.com/cli | sh && ~/.runelay/bin/runelay setup <your-url>

    It signs you in (approve a code in the browser, no keys to paste), registers runelay in every agent it finds with one key per agent, brings the MCP servers, memories, skills and instructions you already have, writes the brief and runs runelay doctor. Restart your agents to load the tools.

    Accounts already logged in arrive connected; the rest wait in the panel's reconnect queue. Each step also exists on its own: runelay login, connect, migrate, pull and doctor.

  4. 4

    Stay up to date

    When a new release is out, an update button shows up in the panel. One click, no terminal.
