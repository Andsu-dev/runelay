Configurar o runelay

Poucos minutos do zero até todos os agentes conectados. Siga os passos ou entregue tudo para o seu agente.

Deixe o Claude Code fazerCopie as instruções, cole no Claude Code (ou Codex, Cursor, qualquer agente com terminal) e ele instala para você.

Passo a passo

Sem terminal? Baixe o app desktop para Mac, Windows ou Linux. Depois de criar a conta, Conectar meus agentes e Conectar minhas contas fazem o resto. Os passos abaixo são para um servidor e o terminal.

  1. 1

    Instale o servidor

    Em qualquer máquina com Docker: uma VPS, um servidor em casa ou este notebook.

    $curl -fsSL runelay.com/install | sh

    Ele cria o ~/runelay/.env com um RUNELAY_SECRET novo. Guarde uma cópia: sem ele as conexões não abrem.

    Prefere sem Docker? Baixe o app desktop.

  2. 2

    Crie a conta dona

    Abra o link de primeiro acesso que o instalador imprime. Ele vale uma vez; depois o cadastro fecha.

  3. 3

    Conecte este computador

    Uma linha instala a CLI e roda o runelay setup com o endereço do seu servidor (ou o que o app desktop mostra).

    $curl -fsSL runelay.com/cli | sh && ~/.runelay/bin/runelay setup <sua-url>

    Ele entra na sua conta (você aprova um código no navegador, sem chave para colar), registra o runelay em todo agente que encontrar com uma chave por agente, traz os servidores MCP, memórias, skills e instruções que você já tem, escreve o brief e roda o runelay doctor. Reinicie os agentes para carregar as tools.

    Contas que já estavam logadas chegam conectadas; o resto espera na fila de reconexão do painel. Cada etapa também existe sozinha: runelay login, connect, migrate, pull e doctor.

  4. 4

    Fique em dia

    Quando sai uma versão nova, aparece um botão de atualizar no painel. Um clique, sem terminal.
