runeley

Um endpoint MCP para todas as contas, skills e memórias que os seus agentes usam. Rodando no seu servidor.

A ideia

Cada agente vive no próprio mundinho. O Claude Code tem os MCPs dele, o Codex outro arquivo, o Cursor outro. Você loga no Linear quatro vezes, copia a mesma skill para quatro pastas, e um esquece o que o outro aprendeu.

💡

O runeley junta tudo atrás de um endpoint MCP que você hospeda. Não é um agente, não roda modelo: é onde o seu agente encontra ferramentas e contexto.

O que tem dentro

  • Conexões. MCP remoto com OAuth, MCP local e qualquer OpenAPI. Login uma vez, cifrado em repouso.
  • Skills. Suas pastas de SKILL.md, buscáveis e servidas sob demanda.
  • Memória. Notas ligadas com [[slug]], com versões. O que um agente aprende, todos leem.
  • Uma chave por agente. Revoga uma sem mexer nas outras.

Subir em um minuto 

git clone https://github.com/Andsu-dev/runeley
cd runeley && docker compose up -d --build

depois é só apontar o Claude Code, Codex, Cursor ou Grok para /v1/mcp ✌️

Funciona com quais agentes?

Qualquer cliente MCP. O comando de import já lê memórias, skills e instruções do Claude Code, Codex, Cursor, Grok, Gemini e OpenCode.

Precisa de algum serviço externo?

Não. Um container, SQLite, e só as contas que você conectar.
