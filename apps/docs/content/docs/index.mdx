Every agent lives on its own island. You log into Linear four times, copy the same skill to four folders, and teach Claude a rule that Codex never hears about.

runelay is the bridge: **one MCP endpoint, on your server**, in front of every account, skill and memory. Claude Code, Codex, Cursor, Antigravity and Grokbot all see the same tools and the same context.

runelay runs no model. Your agent thinks; runelay is where it finds tools and context.

## What you get

| | |
|---|---|
| **Connect once** | About 25 curated MCP servers with one-click OAuth, plus any remote MCP, local MCP or OpenAPI spec. |
| **Shared memory** | Notes linked with `[[slug]]`, versioned, with health checks. What one agent learns, all of them know. |
| **Skills that travel** | Your `SKILL.md` folders, searchable and served on demand. |
| **Import in one go** | Memories, skills and instructions from Claude Code, Codex, Cursor, Grok, Gemini and OpenCode. |
| **One key per agent** | Revoke one without touching the others. Every call is audited. |
| **Yours** | One container, SQLite, no third-party services. MIT licensed. |

## How it fits

Your agents call runelay with a `Bearer rnl_…` key. runelay forwards tool calls to the accounts you connected (Linear, GitHub, Notion or any OpenAPI) and serves your skills and memories.
