Every agent talks to the same endpoint, `PUBLIC_URL/v1/mcp`, with its own API key (`rnl_…`).

The easiest path is the panel: open **Access → Set up agents**. The guide walks you through connecting accounts, creating a key and wiring each client.

To do it all at once from your computer, use the [CLI](/cli): `runelay login`, then `runelay connect`.

## Manual config

Replace the URL and the key with yours.

### Claude Code

```sh
claude mcp add --scope user --transport http runelay https://runelay.example.com/v1/mcp \
  --header "Authorization: Bearer rnl_..."
```

### Codex

```toml title="~/.codex/config.toml"
[mcp_servers.runelay]
url = "https://runelay.example.com/v1/mcp"
http_headers = { Authorization = "Bearer rnl_..." }
```

### Grok

```toml title="~/.grok/config.toml"
[mcp_servers.runelay]
url = "https://runelay.example.com/v1/mcp"
headers = { Authorization = "Bearer rnl_..." }
```

### Cursor

```json title="~/.cursor/mcp.json"
{
  "mcpServers": {
    "runelay": {
      "url": "https://runelay.example.com/v1/mcp",
      "headers": { "Authorization": "Bearer rnl_..." }
    }
  }
}
```
