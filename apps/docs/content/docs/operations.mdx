## Backup

Copy the `data/` folder (the SQLite database) and keep `RUNELAY_SECRET` somewhere safe. Both are needed to restore.

## Update

The panel shows an update button in the rail when a new release is out (owners and admins, with the `updater` service).

By hand:

```sh
cd ~/runelay && docker compose pull && docker compose up -d
```

From source:

```sh
git pull && docker compose up -d --build
```

Migrations run on startup.

## Health

`GET /health` returns `ok`. The container has a healthcheck.

## First-access link

If you lost the signup link, it shows up in the logs:

```sh
cd ~/runelay && docker compose logs runelay
```
