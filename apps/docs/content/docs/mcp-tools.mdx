| Tool | What it does |
|---|---|
| `list_connections` | Every connection with status and tool count. |
| `search_tools` | Search tools across all connections (`source.tool`). |
| `call_tool` | Call one tool with arguments. |
| `execute` | Run JavaScript that chains tools inside a WebAssembly sandbox. |
| `search_context` | Full-text search across memories and skills. |
| `read_memory` / `write_memory` | Read a memory, or create and update one (versioned). |
| `import_memory` | Create or update up to 200 memories in one call. |
| `read_skill` / `read_skill_file` | Read a skill and its files. |
| `write_skill` / `write_skill_file` | Create or update a skill and its files. |

## Memories

`write_memory` creates or updates one memory. When the slug is new but looks like an existing memory, the result has a `similar` list. Read those first and update one of them instead of saving a duplicate.

### import_memory

`import_memory` moves memories in bulk, for example from an agent that kept its own memory.

```json
{
  "items": [
    {
      "slug": "deploy-rules",
      "name": "Deploy rules",
      "description": "Merge to main deploys.",
      "type": "feedback",
      "body": "Merging to main publishes the worker.",
      "createdAt": "2026-08-11T10:00:00Z"
    }
  ]
}
```

- `items` takes up to 200 entries. Send more in batches.
- Only `slug` and `body` are required.
- The result lists each item as `created`, `updated` or `skipped`.

Strip secrets, tokens and passwords before you send anything.

## Skills

`write_skill` creates or updates a skill: `slug`, `body` (the `SKILL.md` content), and optional `name` and `description`. `write_skill_file` adds or replaces one extra file in a skill: `slug`, `path` and `content`.

## execute

`execute` lets an agent chain several calls in one round trip:

```js
await tools.linear.list_issues({...})
```

Code runs in QuickJS compiled to WebAssembly: a fresh sandbox per run with no filesystem, network, process or timers, 32 MB of memory and CPU and wall-clock limits. Tools cross the boundary as JSON only. Turn it off with `RUNELAY_ENABLE_EXECUTE=false` if you only want single `call_tool` calls.

Agents never receive credentials: `list_connections` shows headers and env values as `••••••`.
