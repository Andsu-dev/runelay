Every agent talks to the same endpoint, `PUBLIC_URL/v1/mcp`, with its own API key (`rnl_…`).

The easiest path is the panel: open **Access → Set up agents**. The guide walks you through connecting accounts, creating a key and wiring each client.

To do it all at once from your computer, use the [CLI](/cli): `runelay login`, then `runelay connect`. `connect` also turns off each agent's native memory ([what changes per agent](/cli#native-memory)), so memory goes only to runelay. `runelay doctor` checks the result.

## Hosted agents

A bot hosted by someone else has no access to your computer. It cannot read your config files, and it cannot reach `127.0.0.1`. Run runelay on a public HTTPS URL, create a key for the bot, and add runelay as a remote MCP connector. The [Grok Bot section](/connect-agents/grok#hosted-grok-bot) walks through it, including how to move the bot's memories with `import_memory`.

## Per agent

Each page has the config block and how to load it.

- [Claude Code](/connect-agents/claude-code): One `claude mcp add` command.
- [Codex](/connect-agents/codex): One block in `~/.codex/config.toml`.
- [agentes.chat](/connect-agents/agentes-chat): One MCP by URL in Settings, on a public https address.
- [Cursor](/connect-agents/cursor): One block in `~/.cursor/mcp.json`.
- [Grokbot](/connect-agents/grok): One block in `~/.grok/config.toml`, or a remote connector for a hosted Grok Bot.
- [Antigravity](/connect-agents/antigravity): One block in `mcp_config.json`.
- [Hermes Agent](/connect-agents/hermes-agent): One block in `~/.hermes/config.yaml`.
- [OpenClaw](/connect-agents/openclaw): One `openclaw mcp set` command.
- [MausBot](/connect-agents/mausbot): One pasted command in **Plugins**.
- [OpenCode](/connect-agents/opencode): One block in `opencode.json`.
- [OpenBot](/connect-agents/openbot): One custom MCP in the panel.
- [Kimi Code](/connect-agents/kimi-code): One block in `~/.kimi-code/mcp.json`.
