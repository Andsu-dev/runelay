Add runelay to OpenBot with your endpoint and an agent key (`rnl_…`). Replace the URL and the key with yours; with the desktop app the URL is `http://127.0.0.1:4312/v1/mcp`.

```txt
Server URL   https://runelay.example.com/v1/mcp
Header       Authorization: Bearer rnl_...
```

Open **MCP servers → Connect a custom MCP**, fill **Server URL**, use **Add header** for `Authorization`, and run **Test**. OpenBot hands the server to each agent when a session starts, so start a new session.

No CLI shortcut yet: `runelay connect` does not write OpenBot.

Step by step, with what OpenBot gets once connected: [runelay.com/guides/openbot](https://runelay.com/guides/openbot/).
