Add runelay to Hermes Agent with your endpoint and an agent key (`rnl_…`). Replace the URL and the key with yours; with the desktop app the URL is `http://127.0.0.1:4312/v1/mcp`.

<Callout>
These bots usually run on a server so they can answer in chat around the clock. A server cannot reach `127.0.0.1` on your laptop, so run runelay on the same server or anywhere the bot reaches over HTTPS.
</Callout>

```yaml title="~/.hermes/config.yaml"
mcp_servers:
  runelay:
    url: "https://runelay.example.com/v1/mcp"
    headers:
      Authorization: "Bearer rnl_..."
```

Run `/reload-mcp` in a Hermes session, or restart Hermes. A running `hermes gateway run` picks up the change within about a minute. The tools show up as `mcp_runelay_*`, and a `tools` block with `include` or `exclude` filters them.

No CLI shortcut yet: `runelay connect` does not write Hermes.

Step by step, with what Hermes Agent gets once connected: [runelay.com/guides/hermes-agent](https://runelay.com/guides/hermes-agent/).
