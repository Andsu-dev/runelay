Add runelay to Cursor with your endpoint and an agent key (`rnl_…`). Replace the URL and the key with yours; with the desktop app the URL is `http://127.0.0.1:4312/v1/mcp`.

```json title="~/.cursor/mcp.json"
{
  "mcpServers": {
    "runelay": {
      "url": "https://runelay.example.com/v1/mcp",
      "headers": { "Authorization": "Bearer rnl_..." }
    }
  }
}
```

Reload Cursor so it picks up the new server.

`runelay connect` does this for you.

Step by step, with what Cursor gets once connected: [runelay.com/guides/cursor](https://runelay.com/guides/cursor/).
