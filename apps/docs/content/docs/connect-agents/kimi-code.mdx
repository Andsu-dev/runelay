Add runelay to Kimi Code CLI with your endpoint and an agent key (`rnl_…`). Replace the URL and the key with yours; with the desktop app the URL is `http://127.0.0.1:4312/v1/mcp`.

```json title="~/.kimi-code/mcp.json"
{
  "mcpServers": {
    "runelay": {
      "url": "https://runelay.example.com/v1/mcp",
      "headers": { "Authorization": "Bearer rnl_..." }
    }
  }
}
```

An entry with a `url` and no `transport` is an HTTP server. `$KIMI_CODE_HOME/mcp.json` replaces the path when that variable is set, and `/mcp-config` in the TUI edits the same list. To keep the key out of the file, use `bearerTokenEnvVar` with the name of an environment variable that holds it.

A server added in `mcp.json` joins only sessions created after the change. Open a new session and run `/mcp` to see runelay connected.

No CLI shortcut yet: `runelay connect` does not write Kimi Code.

Step by step, with what Kimi Code gets once connected: [runelay.com/guides/kimi-code](https://runelay.com/guides/kimi-code/).
