Add runelay to Codex with your endpoint and an agent key (`rnl_…`). Replace the URL and the key with yours; with the desktop app the URL is `http://127.0.0.1:4312/v1/mcp`.

```toml title="~/.codex/config.toml"
[mcp_servers.runelay]
url = "https://runelay.example.com/v1/mcp"
http_headers = { Authorization = "Bearer rnl_..." }
```

Open a new Codex session.

`runelay connect` does this for you. It also turns Codex's native memory off, so Codex saves memory only in runelay:

```toml title="~/.codex/config.toml"
[features]
memories = false

[memories]
generate_memories = false
use_memories = false
```

`runelay migrate` also archives `~/.codex/memories` into `~/.runelay/archive/<timestamp>/` after importing it. See the [native memory table](/cli#native-memory) for the other agents, and run `runelay doctor` to check.

Step by step, with what Codex gets once connected: [runelay.com/guides/codex](https://runelay.com/guides/codex/).
