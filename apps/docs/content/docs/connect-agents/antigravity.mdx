Add runelay to Antigravity with your endpoint and an agent key (`rnl_…`). Replace the URL and the key with yours; with the desktop app the URL is `http://127.0.0.1:4312/v1/mcp`.

```json title="~/.gemini/config/mcp_config.json"
{
  "mcpServers": {
    "runelay": {
      "serverUrl": "https://runelay.example.com/v1/mcp",
      "headers": { "Authorization": "Bearer rnl_..." }
    }
  }
}
```

Save the file and reopen Antigravity. To find the file, use **View raw config** under **Manage MCP Servers** in the IDE, or **Copy Config File Path** under **Customizations** in the app. `.agents/mcp_config.json` in a workspace covers one project.

No CLI shortcut yet: `runelay connect` does not write Antigravity.

Step by step, with what Antigravity gets once connected: [runelay.com/guides/antigravity](https://runelay.com/guides/antigravity/).
