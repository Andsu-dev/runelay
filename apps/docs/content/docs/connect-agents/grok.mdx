Add runelay to Grokbot with your endpoint and an agent key (`rnl_…`). Replace the URL and the key with yours; with the desktop app the URL is `http://127.0.0.1:4312/v1/mcp`.

```toml title="~/.grok/config.toml"
[mcp_servers.runelay]
url = "https://runelay.example.com/v1/mcp"
headers = { Authorization = "Bearer rnl_..." }
```

Open a new Grokbot session. A `.grok/config.toml` inside a repo can override the global entry.

`runelay connect` does this for you.

Step by step, with what Grokbot gets once connected: [runelay.com/guides/grokbot](https://runelay.com/guides/grokbot/).
