Add runelay to Claude Code with your endpoint and an agent key (`rnl_…`). Replace the URL and the key with yours; with the desktop app the URL is `http://127.0.0.1:4312/v1/mcp`.

```sh
claude mcp add --scope user --transport http runelay https://runelay.example.com/v1/mcp \
  --header "Authorization: Bearer rnl_..."
```

Open a new Claude Code session. `--scope user` makes runelay available in every project.

`runelay connect` does this for you. It also turns Claude Code's native memory off by setting `autoMemoryEnabled: false` in `~/.claude/settings.json`, so Claude Code saves memory only in runelay. `runelay migrate` does the same and archives the imported memory folders into `~/.runelay/archive/<timestamp>/`. See the [native memory table](/cli#native-memory) for the other agents.

Run `runelay doctor` afterwards to check that everything is in place.

Step by step, with what Claude Code gets once connected: [runelay.com/guides/claude-code](https://runelay.com/guides/claude-code/).
