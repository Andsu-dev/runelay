## What comes along

| | Read from |
|---|---|
| MCP servers | `[mcp_servers.*]` in `~/.grok/config.toml` |
| Logins | `~/.grok/mcp_credentials.json` |
| Global instructions | `~/.grok/AGENTS.md`, as the pinned memory `instrucoes-globais-grok` |
| Skills | `~/.grok/skills` |

Headers come from `headers`. Grokbot keeps its MCP logins in a file, so OAuth accounts arrive connected on every platform, with no Keychain prompt.

## What stays behind

- Memories: runelay does not read a memory folder from Grokbot.
- Servers with a `command` (stdio) stay in Grokbot.
- Accounts without a saved login ask for sign-in in `/connectors/reconnect`.

## Wiring runelay in

If `~/.grok/config.toml` exists, runelay writes (or replaces) its own block:

```toml title="~/.grok/config.toml"
[mcp_servers.runelay]
url = "<url>/v1/mcp"
headers = { Authorization = "Bearer rnl_…" }
```

With `--replace`, the migrated `[mcp_servers.*]` blocks are removed from the file. See [Connect agents](/connect-agents/grok).
