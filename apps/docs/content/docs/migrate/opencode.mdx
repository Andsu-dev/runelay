## What comes along

| | Read from |
|---|---|
| MCP servers | `mcp` in `~/.config/opencode/opencode.json` (servers with a `url`) |
| Global instructions | `~/.config/opencode/AGENTS.md`, as the pinned memory `instrucoes-globais-opencode` |
| Skills | `~/.config/opencode/skills` |

Servers that authenticate with headers arrive connected. Servers with `"enabled": false` are not imported.

## What stays behind

- **Logins.** runelay does not read OpenCode's OAuth tokens. OAuth accounts arrive as connections that ask for login in `/connectors/reconnect`.
- **Local servers** stay in OpenCode.
- Memories: runelay does not read a memory folder from OpenCode.

## Wiring runelay in

`runelay migrate` and `runelay connect` register runelay in `opencode.json` as `mcp.runelay` with `"type": "remote"`, `url: <url>/v1/mcp`, `"enabled": true`, `"oauth": false` and the header `Authorization: Bearer rnl_…`. `runelay pull` writes the brief into `~/.config/opencode/AGENTS.md`.

With `--replace`, the migrated servers are removed from `opencode.json`.
