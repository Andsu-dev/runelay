Sentry is in the runelay catalog under **For developers**. Once it is connected, every agent that uses runelay can call its tools.

| | |
|---|---|
| **Auth** | OAuth |
| **MCP URL** | `https://mcp.sentry.dev/mcp` |
| **Connection name** | `sentry` |
| **Tool prefix** | `sentry.` |

## Add it

1. Open **Connectors → Catalog** in the runelay panel.
2. Press **+** next to Sentry.
3. A new tab opens on Sentry's sign-in page. Approve access and the tab closes on its own.

The connection is saved even if the sign-in tab does not open. Finish it later with **Finish sign-in** on the catalog row, or from the sign-ins queue at `/connectors/reconnect`. See [OAuth window not opening](/troubleshooting#oauth-window-not-opening).

## Use it

Agents find Sentry's tools with `search_tools` and run them with `call_tool` or `execute`. Tool names start with `sentry.`. See [MCP tools](/mcp-tools).

The tools come from Sentry's MCP server and can change on their side, so this page does not list them. The connection page in the panel shows how many tools it exposes right now.

## Without the catalog

The catalog entry is a remote MCP connection to `https://mcp.sentry.dev/mcp`. You can add the same URL as a [custom connection](/connections#remote-mcp) under another name.
