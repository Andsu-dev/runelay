Box is in the runelay catalog under **Work and content**. Once it is connected, every agent that uses runelay can call its tools.

| | |
|---|---|
| **Auth** | OAuth |
| **MCP URL** | `https://mcp.box.com` |
| **Connection name** | `box` |
| **Tool prefix** | `box.` |

## Add it

1. Open **Connectors → Catalog** in the runelay panel.
2. Press **+** next to Box.
3. A new tab opens on Box's sign-in page. Approve access and the tab closes on its own.

The connection is saved even if the sign-in tab does not open. Finish it later with **Finish sign-in** on the catalog row, or from the sign-ins queue at `/connectors/reconnect`. See [OAuth window not opening](/troubleshooting#oauth-window-not-opening).

## Use it

Agents find Box's tools with `search_tools` and run them with `call_tool` or `execute`. Tool names start with `box.`. See [MCP tools](/mcp-tools).

The tools come from Box's MCP server and can change on their side, so this page does not list them. The connection page in the panel shows how many tools it exposes right now.

## Without the catalog

The catalog entry is a remote MCP connection to `https://mcp.box.com`. You can add the same URL as a [custom connection](/connections#remote-mcp) under another name.
