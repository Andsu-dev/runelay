Context7 is in the runelay catalog under **For developers**. Once it is connected, every agent that uses runelay can call its tools.

| | |
|---|---|
| **Auth** | None |
| **MCP URL** | `https://mcp.context7.com/mcp` |
| **Connection name** | `context7` |
| **Tool prefix** | `context7.` |

## Add it

1. Open **Connectors → Catalog** in the runelay panel.
2. Press **+** next to Context7.

There is no sign-in: the server is public, so the connection is ready right away.

## Use it

Agents find Context7's tools with `search_tools` and run them with `call_tool` or `execute`. Tool names start with `context7.`. See [MCP tools](/mcp-tools).

The tools come from Context7's MCP server and can change on their side, so this page does not list them. The connection page in the panel shows how many tools it exposes right now.

## Without the catalog

The catalog entry is a remote MCP connection to `https://mcp.context7.com/mcp`. You can add the same URL as a [custom connection](/connections#remote-mcp) under another name.
