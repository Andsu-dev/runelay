Firecrawl is in the runelay catalog under **For developers**. Once it is connected, every agent that uses runelay can search the web and read pages through it.

| | |
|---|---|
| **Auth** | API key |
| **MCP URL** | `https://mcp.firecrawl.dev/v2/mcp` |
| **Connection name** | `firecrawl` |
| **Tool prefix** | `firecrawl.` |

## Add it

1. Create an API key at [firecrawl.dev/app/api-keys](https://www.firecrawl.dev/app/api-keys).
2. Open **Connectors → Catalog** in the runelay panel.
3. Press **+** next to Firecrawl and paste the key.

runelay sends the key as an `Authorization: Bearer` header and stores it encrypted, like any other connection header.

## Use it

Agents find Firecrawl's tools with `search_tools` and run them with `call_tool` or `execute`. Tool names start with `firecrawl.`. See [MCP tools](/mcp-tools).

The tools come from Firecrawl's MCP server and depend on your plan, so this page does not list them. The connection page in the panel shows how many tools it exposes right now.

## Without the catalog

The catalog entry is a remote MCP connection to `https://mcp.firecrawl.dev/v2/mcp` with an `Authorization: Bearer <key>` header. You can add the same URL as a [custom connection](/connections#remote-mcp) under another name. Without a key, Firecrawl's server still answers with a smaller, rate-limited set of tools.
