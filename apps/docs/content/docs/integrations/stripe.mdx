Stripe is in the runelay catalog under **Popular**. Once it is connected, every agent that uses runelay can call its tools.

| | |
|---|---|
| **Auth** | OAuth |
| **MCP URL** | `https://mcp.stripe.com` |
| **Connection name** | `stripe` |
| **Tool prefix** | `stripe.` |

## Add it

1. Open **Connectors → Catalog** in the runelay panel.
2. Press **+** next to Stripe.
3. A new tab opens on Stripe's sign-in page. Approve access and the tab closes on its own.

The connection is saved even if the sign-in tab does not open. Finish it later with **Finish sign-in** on the catalog row, or from the sign-ins queue at `/connectors/reconnect`. See [OAuth window not opening](/troubleshooting#oauth-window-not-opening).

## Use it

Agents find Stripe's tools with `search_tools` and run them with `call_tool` or `execute`. Tool names start with `stripe.`. See [MCP tools](/mcp-tools).

The tools come from Stripe's MCP server and can change on their side, so this page does not list them. The connection page in the panel shows how many tools it exposes right now.

## Without the catalog

The catalog entry is a remote MCP connection to `https://mcp.stripe.com`. You can add the same URL as a [custom connection](/connections#remote-mcp) under another name.
