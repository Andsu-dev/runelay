Cloudflare Docs is in the runelay catalog under **For developers**. Once it is connected, every agent that uses runelay can call its tools.

| | |
|---|---|
| **Auth** | None |
| **MCP URL** | `https://docs.mcp.cloudflare.com/mcp` |
| **Connection name** | `cloudflare_docs` |
| **Tool prefix** | `cloudflare_docs.` |

## Add it

1. Open **Connectors → Catalog** in the runelay panel.
2. Press **+** next to Cloudflare Docs.

There is no sign-in: the server is public, so the connection is ready right away.

## Use it

Agents find Cloudflare Docs's tools with `search_tools` and run them with `call_tool` or `execute`. Tool names start with `cloudflare_docs.`. See [MCP tools](/mcp-tools).

The tools come from Cloudflare Docs's MCP server and can change on their side, so this page does not list them. The connection page in the panel shows how many tools it exposes right now.

## Without the catalog

The catalog entry is a remote MCP connection to `https://docs.mcp.cloudflare.com/mcp`. You can add the same URL as a [custom connection](/connections#remote-mcp) under another name.
