GitHub is in the runelay catalog under **Popular**. Once it is connected, every agent that uses runelay can call its tools.

| | |
|---|---|
| **Auth** | OAuth (or a personal token) |
| **MCP URL** | `https://api.githubcopilot.com/mcp/` |
| **Connection name** | `github` |
| **Tool prefix** | `github.` |

## Add it

1. Open **Connectors → Catalog** in the runelay panel.
2. Press **+** next to GitHub.
3. A new tab opens on GitHub's sign-in page. Approve access and the tab closes on its own.

The login goes through runelay's hosted OAuth broker (`auth.runelay.com`) and asks for the `repo` and `read:user` scopes. GitHub's tokens expire, and runelay refreshes them on its own, so the connection doesn't drop. The connection is saved even if the sign-in tab does not open; finish it later with **Finish sign-in** on the catalog row, or from the sign-ins queue at `/connectors/reconnect`.

### With a token

Pasting a token still works. Create one at [https://github.com/settings/personal-access-tokens/new](https://github.com/settings/personal-access-tokens/new) and paste it on the connection. runelay sends it as an `Authorization: Bearer` header. It is encrypted on the server and agents never see it.

### Your own broker

Self-hosted instances use `auth.runelay.com` and runelay's GitHub app by default. If you run your own broker, set `RUNELAY_OAUTH_BROKER_URL` and `RUNELAY_GITHUB_CLIENT_ID` to your broker and your GitHub OAuth app. See [Self-hosting](/self-hosting#environment-variables).

## Use it

Agents find GitHub's tools with `search_tools` and run them with `call_tool` or `execute`. Tool names start with `github.`. See [MCP tools](/mcp-tools).

The tools come from GitHub's MCP server and can change on their side, so this page does not list them. The connection page in the panel shows how many tools it exposes right now.

## Without the catalog

The catalog entry is a remote MCP connection to `https://api.githubcopilot.com/mcp/`. You can add the same URL as a [custom connection](/connections#remote-mcp) under another name.
