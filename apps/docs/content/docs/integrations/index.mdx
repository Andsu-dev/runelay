icon: Blocks
---

The catalog lives in the panel under **Connectors → Catalog**. Each entry is a remote MCP server or a built-in connector with a known sign-in method, so installing it takes one click:

- **OAuth**: a tab opens on the provider's sign-in page.
- **Personal token**: you paste a token in a dialog.
- **None**: the server is public and connects right away.

Anything that is not in the catalog can still be added as a [custom connection](/connections): any remote MCP, local MCP or OpenAPI spec.
