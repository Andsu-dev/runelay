Buffer is in the runelay catalog under **Work and content**. Once it is connected, every agent that uses runelay can call its tools.

| | |
|---|---|
| **Auth** | Personal token |
| **MCP URL** | `https://mcp.buffer.com/mcp` |
| **Connection name** | `buffer` |
| **Tool prefix** | `buffer.` |

## Add it

1. Create an API token at [publish.buffer.com/settings/api](https://publish.buffer.com/settings/api).
2. Open **Connectors → Catalog** in the runelay panel.
3. Press **+** next to Buffer and paste the token in the dialog.

The token is stored encrypted on your runelay server. Agents only hold their runelay key.

## Use it

Agents find Buffer's tools with `search_tools` and run them with `call_tool` or `execute`. Tool names start with `buffer.`. See [MCP tools](/mcp-tools).

The tools come from Buffer's MCP server and can change on their side, so this page does not list them. The connection page in the panel shows how many tools it exposes right now.

## Without the catalog

The catalog entry is a remote MCP connection to `https://mcp.buffer.com/mcp` with the token sent as a bearer header. You can add the same URL as a [custom connection](/connections#remote-mcp) under another name.
