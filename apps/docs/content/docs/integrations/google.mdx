Google is in the runelay catalog as one connector per service, under **Work and content**. Each one signs in with one click through runelay's hosted OAuth broker (`auth.runelay.com`), so there is no Google Cloud project to set up. Each asks only for its own scopes, plus `openid`, `email` and `profile`, and keeps a refresh token so the connection doesn't drop after an hour.

## Services

| Catalog entry | Connection name | What agents can do | Scopes |
|---|---|---|---|
| Google Calendar | `google_calendar` | List calendars and events, create and delete events. | `calendar`, `calendar.events` |
| Gmail | `gmail` | Send an email (to, subject, body, cc). It can't read mail. | `gmail.send` |
| Google Drive | `google_drive` | Create a text file and list the files runelay created. | `drive.file` |
| Google Docs | `google_docs` | Create a doc, read its text and append text to it. | `documents`, `drive.file` |
| Google Sheets | `google_sheets` | Create a spreadsheet with rows, read a range, overwrite a range and append rows. | `spreadsheets`, `drive.file` |
| Google Slides | `google_slides` | Create a deck with slides of text, read the text of each slide and add a slide. | `presentations`, `drive.file` |
| Google Forms | `google_forms` | Create a form and add questions (text, paragraph, choice, scale). | `forms.body`, `drive.file` |
| Google Meet | `google_meet` | Create a meeting space and return its link. | `meetings.space.created` |

Every tool is runelay's own and calls Google's REST APIs directly, so there is no Google MCP server or preview program involved.

`drive.file` only reaches files runelay created, not the rest of your Drive. Restricted scopes, such as reading Gmail or full Drive access, are not requested on purpose.

## Add it

1. Open **Connectors → Catalog** in the runelay panel.
2. Press **+** next to the Google service you want.
3. A new tab opens on Google's sign-in page. Pick the account, approve the scopes for that service and the tab closes on its own.

Repeat for each service. Every service is its own connection, so you can connect only the ones you need, or use a different Google account for each.

The connection is saved even if the sign-in tab does not open. Finish it later with **Finish sign-in** on the catalog row, or from the sign-ins queue at `/connectors/reconnect`. See [OAuth window not opening](/troubleshooting#oauth-window-not-opening).

## Use it

Agents find the tools with `search_tools` and run them with `call_tool` or `execute`. Tool names follow `<connection>.<service>_<tool>`, for example `gmail.gmail_send_email`. Every Google connection also has `account_whoami`, which returns the Google account it is signed in with. See [MCP tools](/mcp-tools).

## Your own broker

Self-hosted instances use `auth.runelay.com` and runelay's Google app by default. To use your own Google app, deploy the broker from `apps/oauth-broker` and set `RUNELAY_OAUTH_BROKER_URL` and `RUNELAY_GOOGLE_CLIENT_ID`. See [Self-hosting](/self-hosting#environment-variables). Connections made before the change keep the client ID they were created with, so reinstall them from the catalog after switching.
